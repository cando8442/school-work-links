# 부별공유

부서별 공유 폴더를 대신하는 학교 업무 화면입니다. 학교 구글 계정으로 로그인한 교직원만 볼 수 있고,
자료는 구글 드라이브에 두고 이곳에는 링크만 겁니다.

이 프로젝트는 shinnanchanguk 의 미니홈피 링크트리 템플릿(MIT)에서 출발해 학교 부서별 업무 공유 용도로
다시 만든 것입니다. 원 저작권 표시는 LICENSE 파일에 그대로 두었습니다.

## 우리 학교 것으로 만들기

포크할 필요 없이, 이 저장소 링크를 AI 코딩 도구에 주면서 이렇게만 말하면 됩니다.

> 이 깃허브 저장소로 우리 학교 부별공유를 만들고 싶어: https://github.com/cando8442/school-work-links . `docs/SETUP.md`를 읽고 그대로 진행해줘.

직접 하시려면 [docs/SETUP.md](docs/SETUP.md) 의 순서를 따르시면 됩니다.

## 화면

- **교무실(홈)** — 이달 달력, 오늘까지·이번 주 마감, 부서에서 올린 글, 제출 현황, 공용 링크
- **부서 탭** — 부서 공유 드라이브, 게시판, 제출 현황, 업무분장
- **업무분장 상세** — 반복되는 업무, 처리 절차, 인수인계 메모, 서식 내려받기, 관련 링크

## 할 수 있는 일

| | 설명 |
| --- | --- |
| 업무분장 | 부장이 자기 부서 업무를 적고 고칩니다. 반복 업무와 처리 절차를 남겨 인수인계에 씁니다 |
| 마감 | 달력과 목록으로 보고, 항목을 펼쳐 제출용 구글 시트로 바로 들어갑니다 |
| 제출 현황 | 과목명이나 동아리명 단위로 누가 냈는지 표시합니다. 이름을 쓰지 않습니다 |
| 서식 | 업무마다 한글 서식과 시트를 걸어 두고 내려받습니다 |
| 일정 가져오기 | 연간학사일정과 금주의 일정표 PDF 를 읽어 초안을 만듭니다. 주간 일정표는 승인해야 올라갑니다 |
| 바탕화면 바로가기 | 컴퓨터에 익숙하지 않은 선생님도 두 번 눌러 바탕화면에 아이콘을 만듭니다 |

## 권한

| 하는 일 | 누가 |
| --- | --- |
| 보기 | 학교 계정으로 로그인한 모든 사람 |
| 제출 완료 표시, 제출 과제 만들기, 글쓰기 | 학교 계정 누구나 |
| 업무분장·서식·공유 드라이브 링크 | 권한을 받은 사람(부장 등) |
| 권한 주고 빼기 | 최초 관리자 한 명 |

화면에서 버튼을 감추는 데 그치지 않고 Firestore 보안 규칙이 서버에서 막습니다.

## 고치는 곳

| 고치고 싶은 것 | 파일 |
| --- | --- |
| 학교 이름, 도메인, 관리자, 로고 | `src/config/school.ts` |
| 부서 목록과 업무분장 초기값 | `src/config/departments.ts` |
| 공용 링크 | `src/config/linktree.ts` |
| 색 | `src/config/theme.ts` |
| 접근 제한 규칙 | `firestore.rules` (도메인과 관리자 주소 두 곳) |

## 만들 때 지킨 것

- 학생 개인정보를 수집하거나 저장하지 않습니다. 제출 주체도 이름 대신 과목명·동아리명을 씁니다
- 문서는 이 사이트에 올리지 않고 구글 드라이브에 두며 링크만 겁니다. 실제 열람 제한은 드라이브 권한이 합니다
- 보안 헤더(CSP, 클릭재킹 방어, HSTS 등)를 넣어 dorms-check 보안 검토 98점(A+)을 받았습니다
